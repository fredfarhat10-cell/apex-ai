# App Design System: Momentum

## Brand Personality
Tone: Confident ally, not drill sergeant. Celebrates progress, never guilts.
Feel: Energizing but calm. Like a coach who believes in you.

## Colors
Primary: #3B82F6 (Blue) — trust, action
Secondary: #22C55E (Growth Green) — progress, achievement
Accent: #F59E0B (Victory Gold) — celebration, rewards
Background: #0B1120 (Deep Navy) — immersive, focused
Surface: #131C2E (Card Dark) — depth, separation
Surface-Alt: #1A2332 (Elevated Dark) — interactive elements
Text: #F1F5F9 (Cloud White) — readable, clean
Muted: #64748B (Slate) — secondary info
Border: rgba(255, 255, 255, 0.05) — subtle separation
Danger: #E53E3E (Alert Red) — ONLY for opt-in challenges, never shame

## Typography
Display: "DM Serif Display" — warmth + authority
Headlines: "Inter Bold" — clean, modern
Body: "Inter Regular" — readable, friendly
Mono: "JetBrains Mono" — data/stats

## Spacing
Base unit: 4px
Scale: 4, 8, 12, 16, 24, 32, 48, 64, 96

## Radius
Small: 8px (buttons, inputs)
Medium: 12px (cards)
Large: 16px (modals, feature cards)
XL: 20px (main cards)
Full: 9999px (avatars, pills, circular buttons)

## Motion
Duration: 150ms (micro), 300ms (transitions), 500ms (celebrations)
Easing: cubic-bezier(0.4, 0, 0.2, 1)
Spring: stiffness 500, damping 30

## Shadows
Card: 0 4px 24px rgba(0, 0, 0, 0.3)
Glow-Blue: 0 0 20px rgba(59, 130, 246, 0.3)
Glow-Green: 0 0 20px rgba(34, 197, 94, 0.3)
Glow-Gold: 0 0 20px rgba(245, 158, 11, 0.3)

## Principles
1. Celebration > Guilt
2. Progress > Perfection
3. Community > Competition
4. Flexibility > Rigidity
5. Zero red for missed days — ever
6. Supportive language only — no shame
